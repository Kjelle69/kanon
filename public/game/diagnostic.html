The Cannon Game

Host simulerar båda borgarna och renderar två 640×480-kameror.
Spelare 2 får endast en videoström och skickar styrkommandon.

Sikta med WASD eller piltangenter. Blanksteg skjuter. Klicka i spelfönstret för tangentbordsfokus. Host kan testa båda kamerorna med förhandsgranskningen.

Teknik

3D med Three.js/WebGL. Enkel bollistik och stenfysik i JavaScript på hosten. WebRTC-video via canvas.captureStream() och DataChannel för styrning. Inga nätverkssynkade fragment.

OBS: Extern internetanslutning krävs för att ladda Three.js. WebRTC kan behöva en TURN-reläserver för vissa NAT-/mobilnät. Testa helst först två flikar eller två datorer på samma nät.
